tags: ['Análisis Numérico (Completo)']

> El salto $h$ se define según la precisión deseada, ya que son los saltos que se definen entre iteraciones.
> 

> En este caso, para un tiempo $t_i$, cuando se refiere a $t_{i+1}$ es el siguiente instante de tiempo, sin embargo, esto esta dado por $t_{i+1} = t_i + h$
>
